bangla-llm-eval

A small, fixed, reproducible Bangla (Bengali) evaluation of large language models: translation both ways, natural-language inference, and Bengali-digit numerals. 270 items, one live run per model on 2026-10-17. Every number below is recomputed in CI from the committed raw model outputs.

{{HEAD}}{{BODY}}

chrF++ is corpus-level (sacrebleu, word order 2) on 60 FLORES-200 devtest sentences per direction. NLI accuracy is on 90 balanced items from the Bengali XNLI test split. Numerals is exact match on 60 items (30 arithmetic in Bengali digits, 30 Bengali-to-ASCII digit transcriptions). Cost is at list prices from the token counts the providers returned. Rows are ordered by the sum of the four quality scores.

Limits: one run per model, small per-task samples (differences of a few points are within noise), and FLORES-200 is public, so contamination cannot be ruled out. Details, raw outputs and the one-command repro are in the repository.
